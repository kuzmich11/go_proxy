# Go Proxy Server

Прямой прокси-сервер на Golang с поддержкой подмены заголовков для скрытия реального местоположения.

## Возможности

- **HTTP/HTTPS прокси** - полная поддержка HTTP и HTTPS (CONNECT) протоколов
- **SOCKS5 прокси** - поддержка всех протоколов через SOCKS5
- **Подмена заголовков** - маскировка реального IP и местоположения
- **Потоковая передача** - эффективная потоковая передача данных для видео и больших файлов
- **Graceful shutdown** - корректное завершение работы при получении сигнала

## Запуск

```bash
go run main.go
```

Сервер запустится на следующих портах:
- HTTP/HTTPS прокси: `:8080`
- SOCKS5 прокси: `:1080`

## Использование

### HTTP/HTTPS прокси

Установите прокси в вашем браузере или приложении:
```
Адрес: localhost
Порт: 8080
```

Пример использования с curl:
```bash
curl -x http://localhost:8080 https://example.com
```

### SOCKS5 прокси

Установите SOCKS5 прокси:
```
Адрес: localhost
Порт: 1080
```

Пример использования с curl:
```bash
curl --socks5 localhost:1080 https://example.com
```

## Подмена заголовков

Прокси автоматически подменяет следующие заголовки для скрытия реального местоположения:

- `User-Agent` - маскировка браузера
- `Accept-Language` - изменение языковых предпочтений
- `X-Forwarded-For` - удаление реального IP
- `X-Real-IP` - удаление реального IP
- `Via` - добавление информация о прокси

Дополнительно удаляются hop-by-hop заголовки:
- `Connection`
- `Keep-Alive`
- `Proxy-Authorization`
- `Transfer-Encoding`
- `Upgrade`

## Конфигурация

Измените конфигурацию в файле `main.go`:

```go
var config = ProxyConfig{
    HTTPAddr:      ":8080",        // HTTP/HTTPS порт
    SOCKS5Addr:    ":1080",        // SOCKS5 порт
    ViaProxy:      true,           // Добавлять Via заголовок
    HideIP:        true,           // Скрывать реальный IP
    CustomHeaders: make(map[string]string),
}
```

## Потоковая передача видео

Прокси оптимизирован для потоковой передачи видео:
- Отсутствие таймаутов для длительных соединений
- Буферизация для плавного воспроизведения
- Поддержка Range-запросов для частичной загрузки

## Тестирование

Проверка HTTP прокси:
```bash
curl -v -x http://localhost:8080 https://httpbin.org/headers
```

Проверка SOCKS5 прокси:
```bash
curl -v --socks5 localhost:1080 https://httpbin.org/ip
```
